# Open Intimacy SVG

Open-source human relationship and health education illustration library.

## Design goals

- SVG only, no AI generated raster images
- Vector human model system
- Front and side view support
- Pose-friendly joint structure
- Educational illustration style inspired by safety instruction diagrams

## v0.1 Human System

Initial components:

- male front view
- female front view
- male side view
- female side view

Future:

- skeleton/joint data
- pose JSON format
- SVG pose editor
- GitHub Pages viewer
